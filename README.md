# Bitcoin Live Ticker

A beautiful, real-time Bitcoin price ticker with live updates every 5 minutes.

## Features

- **Live Price Updates**: Auto-refreshes every 5 minutes using CoinGecko API
- **Price Change Indicator**: Shows 24h change with color-coded trends
- **Market Stats**: 24h high/low, market cap, and trading volume
- **Price Chart**: Interactive 24-hour price history visualization
- **Glassmorphism Design**: Modern dark theme with stunning glass effects
- **Fully Responsive**: Works perfectly on desktop, tablet, and mobile

## Live Demo

🚀 **View it live**: https://im360john.github.io/demo-portfolio/

## Technologies

- HTML5
- CSS3 (Glassmorphism, CSS Grid, Flexbox)
- Vanilla JavaScript
- CoinGecko API (free, no API key required)
- Canvas API for charts
